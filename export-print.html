Export & Print

Export to PDF, HTML, or print directly from the app.

Export to PDF

Go to File → Export → PDF. The PDF preserves themes, KaTeX formulas, and Mermaid diagrams.

Export to HTML

Go to File → Export → HTML. Produces a standalone page with embedded styles.

Print

Go to File → Print or press Ctrl+P / Cmd+P.
