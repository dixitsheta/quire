About Quire

A lightweight, fast Markdown viewer and editor.

What is Quire?

Quire is an Electron-based Markdown viewer and editor designed for speed and simplicity. It renders Markdown files with live preview, supports custom themes, and exports to PDF and HTML.

Features

  • Live preview as you type
  • Light and dark themes
  • Export to PDF, HTML, and print
  • GitHub-style Markdown rendering
  • Cross-platform (macOS, Windows, Linux)
